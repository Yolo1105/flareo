\`\`\`
+--------------------------------------------------+

| +----------------+  +-------------------------+  |
|                                                  |
| +--------------------------------------------------+
| | 全部 | 提问 | 建议 | 教程 | (Tab栏)              |
| +--------------------------------------------------+
|                                                  |
| +------------------------+  +------------------+ |
| |                        |  |                  | |
| |                        |  |  🎯 热门话题标签  | |
| |                        |  |                  | |
| |                        |  +------------------+ |
| |                        |                      |
| |  左侧主内容区           |  +------------------+ |

| |                        |                      |

| |                        |  |                  | |
| |                        |  +------------------+ |

|                                                  |
+--------------------------------------------------+
\`\`\`

### 帖子卡片设计
\`\`\`
+--------------------------------------------------+
| 📌 帖子标题 (点击进入详情页)                      |
| 📄 内容摘要 (最多三行)...                        |
| 🔗 #插件标签1 #插件标签2                         |
| 👤 作者名 | 🕒 2小时前 | 👍 24 | 💬 8            |
+--------------------------------------------------+
\`\`\`

### 响应式设计考虑
- 在移动设备上，右侧栏移至底部
- 帖子卡片在移动设备上占满宽度
- 搜索框和筛选器在移动设备上垂直排列

| |                        |  |                  | |

\`\`\`

### 评论设计
\`\`\`
+--------------------------------------------------+
| 👤 评论者名称 | 🕒 时间                           |
| 评论内容...                                      |
| 👍 点赞 | 💬 回复 | 🔖 收藏                      |
|   +----------------------------------------------+
|   | 👤 回复者名称 | 🕒 时间                      |
|   | 回复内容...                                 |
|   | 👍 点赞 | 💬 回复                           |
|   +----------------------------------------------+
+--------------------------------------------------+
\`\`\`

### 响应式设计考虑
- 在移动设备上，右侧栏移至正文内容下方
- 评论区在移动设备上保持嵌套结构但减少缩进
- 操作按钮在移动设备上使用图标减少空间占用

| +------------------+  +-------------------------+ |

+--------------------------------------------------+
\`\`\`

### Markdown预览区域
\`\`\`
+--------------------------------------------------+
| 📌 预览: 您的标题                                |
| ------------------------------------------       |
| 渲染后的Markdown内容...                          |
| 图片、代码块、列表等                              |
| ------------------------------------------       |
| #插件标签1 #插件标签2                            |
+--------------------------------------------------+
\`\`\`

### 响应式设计考虑
- 在移动设备上，编辑器工具栏简化为常用功能
- 预览和发布按钮在移动设备上垂直排列
- 附件上传区域在移动设备上简化为单一按钮

## 6. 技术导航仪（推荐页）UI 布局

\`\`\`
+--------------------------------------------------+
|                  全局导航栏                       |
+--------------------------------------------------+
|                                                  |
| +--------------------------------------------------+
| | 🔍 我需要: [输入您的需求...]                     |
| | 例如: "我想把音频转成文字并翻译成英文"           |
| +--------------------------------------------------+
|                                                  |
| +--------------------------------------------------+
| | 🧠 为您推荐的插件组合                           |
| +--------------------------------------------------+
|                                                  |
| +--------------------------------------------------+
| | 推荐方案 1:                                     |
| |                                                |
| | +----------------------------------------------+ |
| | | 🌐 部署路径可视图                            | |
| | |                                              | |
| | | [插件1] → [插件2] → [插件3]                  | |
| | | ↓                                            | |
| | | [插件4] ←                                    | |
| | |                                              | |
| | +----------------------------------------------+ |
| |                                                |
| | 📝 方案说明:                                   |
| | 这个组合首先使用插件1进行音频转文字，然后...     |
| |                                                |
| | 🧩 包含插件:                                   |
| | • 插件1: 音频转文字 (4.8⭐)                     |
| | • 插件2: 文本翻译 (4.9⭐)                      |
| | • 插件3: 语法校对 (4.7⭐)                      |
| |                                                |
| | +----------------+  +-------------------------+ |
| | | 👁️ 查看详情    |  | 🚀 一键部署             | |
| | +----------------+  +-------------------------+ |
| +--------------------------------------------------+
|                                                  |
| +--------------------------------------------------+
| | 推荐方案 2:                                     |
| | ...                                            |
| +--------------------------------------------------+
|                                                  |
| +--------------------------------------------------+
| | 🔍 其他用户还搜索了:                            |
| | "音频转字幕" | "多语言翻译" | "文本摘要"        |
| +--------------------------------------------------+
|                                                  |
+--------------------------------------------------+
\`\`\`

### 方案详情页
\`\`\`
+--------------------------------------------------+
| 📌 方案名称: 音频转文字并翻译                     |
| ------------------------------------------       |
| 🌐 完整部署路径图 (可交互)                        |
| ------------------------------------------       |
| 📝 详细工作流程说明                               |
| ------------------------------------------       |
| 🧩 插件详情:                                     |
| • 插件1: 详细介绍、评分、价格                     |
| • 插件2: 详细介绍、评分、价格                     |
| • ...                                           |
| ------------------------------------------       |
| 💰 总成本: ¥XX                                   |
| ⏱️ 预计处理时间: XX分钟                          |
| ------------------------------------------       |
| 🚀 一键部署 | 🛒 添加到购物车                     |
+--------------------------------------------------+
\`\`\`

### 响应式设计考虑
- 在移动设备上，部署路径可视图简化为线性流程
- 查看详情和一键部署按钮在移动设备上垂直排列
- 推荐方案在移动设备上完全垂直排列
