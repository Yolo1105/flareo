选择上传方式

请选择一种方式上传您的插件代码。我们支持多种上传方式，选择最适合您的开发流程的方式。

Dockerfile 上传

上传包含 Dockerfile 的项目目录，我们将自动构建并部署您的插件。

镜像 TAR 包

上传预先构建好的 Docker 镜像 TAR 包，适合有特殊构建需求的插件。

GitHub 仓库

直接关联 GitHub 仓库，我们将自动拉取最新代码并构建部署。

发布协议

插件发布协议

通过发布插件，您同意以下条款：

  1. 您拥有或已获授权发布此插件的所有内容
  2. 您的插件不包含恶意代码或侵犯他人知识产权的内容
  3. 您同意平台对每笔交易收取15%的服务费
  4. 您将及时响应用户的问题和反馈
  5. 您同意遵守平台的社区准则和服务条款
